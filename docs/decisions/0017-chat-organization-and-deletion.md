# 0017：项目仅归类，聊天独立与确认删除

日期：2026-10-28。

## 锁定语义

- 项目是侧栏文件夹；原“我的工作台”作为既有项目原样保留，可重命名。
- 普通新聊天的 `sessions.project_id` 为 NULL，不隐式创建或选择默认项目。
- 项目内聊天显式指定项目；项目归类不授予读取其他聊天历史、账号或记忆的权限。
- 会话历史仍由原 LangGraph thread/checkpoint 管理，领域记录仍以 session 为边界。
- 会话拥有者回填自既有项目，独立聊天直接记录拥有者；不搬迁、清空或重新执行历史测试。
- 长期记忆调用在 owner/session 命名空间内读写；项目不再是聊天间经验共享的通道。
  既有共享记忆原件保留，但新调用不会隐式读取这些旧命名空间。
- 新建身份绑定当前 session；旧身份记录保留，只允许其明确设为 active 的会话使用。

## 确认删除

替代旧“只隐藏会话、保留全部审计”的删除接口语义。用户确认后，在同一 PostgreSQL
事务中删除指定会话的业务记录、无外键台账、checkpoint 与会话记忆。其他会话不变。
有活动运行、未终结任务或未关闭执行资源时返回 409，保留对话和管理入口。
显式选择终止资源时沿用已有执行端关闭协议，不能把关闭请求当作已关闭。

删除不清空项目，也不扫描删除共享 CAS 文件或既有备份；不同工件可复用相同哈希原件。
技能库共享工件保留共享引用。数据库结构迁移只增列、放宽空项目归属并回填拥有者。

## 验证边界

使用隔离数据库验证 API、删除范围、权限和记忆独立性；不对日常数据执行删除测试。
部署前备份数据库与工件，记录既有主键集合，部署后核对历史记录仍存在。
真实模型效果和真实靶场实验仍由用户单独执行。
