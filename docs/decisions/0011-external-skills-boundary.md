# 0011：仅允许用户主动接入外部 Skill

2026-10-21，恢复已确认的外部方法论边界。

## 问题与决定

回档到引入任务合同前的 `c85c682` 时，也带回了把宿主 methods 发布成 builtin Skill、默认装配 Skill 工具和中间件的旧实现。单纯回档无法保留后来确认的外部方法论边界，因此在该基线上恢复仅限 Skill 接入层的修复。

1. 发布只接受 `user:` / `zip:`。显式刷新只扫描用户根目录；GET 和运行目录发现不触发刷新。
2. 历史 builtin 不出现在可用库存，不能重新启用、项目绑定或执行；保留历史版本和审计读取。
3. 空外部库存保持原工具、提示和中间件，不创建空目录工件或改写 run 配置。`search_methods` 和原计划、证据、结束判定独立保留。
4. Runner 装配时发现已发布外部库存，并按版本固定扩展。旧 checkpoint 停在 Skill hook 时，仅装配不读库、不写状态、不重放工具的兼容节点。
5. 修复及边界测试进入正常提交。保留无任务合同的基线，不重新引入任务合同、责任树或其他后续设计。

迁移 `a8b3d5f7c012` 仅停用历史 builtin 安装并解除项目绑定，不删除安装、历史包版本或工件。运行时同时过滤非外部来源并拒绝重新启用，避免仅靠数据库标记维持边界。
