# 工具记录紧凑布局验收

工具操作按同一运行中连续出现的记录分组，保留聊天时间顺序。整组默认显示操作行，可点击汇总行“收起”隐藏；收起后仍显示操作数量、进行中数量与失败数量。新操作和状态更新不会自动展开已收起的组。

单条操作默认折叠。展开后，调用参数与返回结果可分别展开、收起。详情沿用现有接口及脱敏规则。每条助手回复前的 Rexak 标识已删除，包含历史回复与流式回复。

正文 15px，工具操作 12px，工具名、状态与耗时 11px；工具标题使用普通字重。折叠操作行高和相邻操作间距均为 24px。

实际 Edge 浏览器验证：整组收起、单条展开、参数与结果分开展开、脱敏、完成和失败状态、收起后的实时更新、刷新后历史展示，以及 390px 窄屏布局。使用官方 Agent 图、真实数据库与可复现模型，未调用真实模型或访问测试目标。结果见 [tool-activity-ui.json](tool-activity-ui.json)，页面见 [桌面截图](tool-activity-compact.png) 和 [窄屏截图](tool-activity-compact-mobile.png)。

前端类型检查与生产构建、验收脚本 Ruff/Pyright、UTF-8 编码检查及差异检查通过。本次仅调整前端展示；刷新网页即可加载，无需重启控制端或 Kali。
