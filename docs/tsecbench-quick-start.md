# 评测快速启动器

双击桌面的 **Rexak 评测启动器**，或仓库根目录的 `start-evaluation.cmd`。
打开窗口不会启动靶场、调用模型或继续历史任务。

连接按钮支持重复尝试：OpenVPN 图形客户端未启动时自动拉起；已有同一配置不会阻止重试。
连接请求发出后等待 Windows VPN 健康检查，通过后才提示连接成功。
若此前窗口出现 `rescan` 失败或“配置已导入”后无法重试，请关闭旧启动器并重新打开。

1. 启动器默认恢复最近保存的平台地址、隐藏 Token 和 VPN 文件；继续同一轮时无需重填。更换平台任务或密钥时，填入新的 Token 并选择该轮 `.ovpn`。
2. 先在 OpenVPN 中断开上一轮 VPN，再点击“连接本轮 VPN”；已连接本轮 VPN 时可跳过。
   若网络持续 TLS 超时，可换手机热点；Kali 仍需通过健康检查。
3. 点击“启动控制台”。在“查看当前做题过程 / 模型设置”打开网页，确认默认模型和 API Key。
   Standard / Ultra 在启动器中选择，默认 Ultra；模型密钥使用原网页配置，不复制到 VPN 或 Kali。
4. 点击“检查并读取题目”，核对当前题集和 flag 数量，选择“单题”或“从所选题目开始（串行）”，再在题目下拉框指定起点。串行模式只处理该题及其后尚未完成的题目，跳过起点之前的题目；每次开始均以本次选择为准。
5. 点击“开始测评”，核对弹窗列出的平台、题量、模式和单题等待上限后确认。

只有第 5 步会启动真实靶场及模型。今天没有使用此入口运行真实测评。

## 查看做题过程

每道题通过原 API 创建独立的 `TSecBench <题号>` 会话。
启动器的“查看当前做题过程”会打开本机 Rexak 网页并定位当前题，
可以查看对话、工具活动、结果和用量；Ultra 还可以查看委派任务。
也可在网页侧栏选择历史题目会话。不同题目不是同一聊天。
这些是本机工作台记录，不等于平台网站会展示同样的实时界面，
也不意味着能够看到模型未公开的内部推理。

## 停止与关闭

- “当前题结束后停止”不再安排下一题；当前题继续正常收尾。
- 要取消当前题，点击启动器“取消当前题并停止”，也可在对应网页点击取消。启动器等待该题及远端执行收尾后停止后续题目。
- 正在测评时关闭窗口可确认取消当前题；核对停止并释放靶场后自动退出，不直接杀死执行进程。
- 失败、取消、未决远端执行、题目丢失或靶场未释放时，串行批次停止，避免串题或叠加运行。
- 闲置时关闭窗口，会关闭由本启动器创建的本地控制台；复用的原有服务不关闭，VPN 连接保留。

## 配置和记录

每次填写的新配置独立保存在 `~/.workbench/tsecbench/profiles/`，原配置不会覆盖。
目录与文件限制为当前用户访问，Token 输入隐藏，不写入命令行或 Git。
本轮启动日志位于该私有配置目录；题目运行记录仍由原流程写入运行数据目录。
启动器不支持断点自动续跑；重开后重新读取平台进度，已完成题目跳过。

本地模式接入与平台托管上榜不同，后者仍需单独准备托管镜像。
