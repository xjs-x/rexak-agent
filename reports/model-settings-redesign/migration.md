# 旧配置迁移与回退

读取旧文件时，将 `endpoints`、`default_provider` 和 `default_model` 合并为内存中的分组目录。小米、百炼现有模型档案和默认偏好随之导入。旧 Key 继续使用原有 DPAPI 凭据槽，旧 `.env` 兼容读取保留。只读浏览和目录查询都不会升级设置文件。

首次成功保存会将供应商目录写入原配置路径，并保留同目录的 `models.v1.backup.json`。该备份仅包含原设置数据。修订号可检测同时打开的设置页是否已基于旧版本编辑。

以原 Provider ID 关联历史阶段。新模型绑定记录固定的真实 Model ID、URL、预算和凭据引用。更换主机时创建新的密钥槽，原槽继续服务引用它的 Run。删除 Provider 会移出新任务目录并保留受保护的历史凭据槽，同名 ID 保留以避免重新指向其他提供商。显式清除当前 Key 会使使用该槽的新请求缺少凭据。

回退到旧版本前，保留升级后的设置文件和本机密钥库。可将 `models.v1.backup.json` 恢复为旧版本的 `models.json`。旧程序只能识别它原本支持的 Provider 和模型，使用自定义 Provider 创建的新 Run 需要保留新版运行时。回退设置文件有别于恢复某个旧 Key，原槽内主动替换的密钥需要独立备份才能恢复。
