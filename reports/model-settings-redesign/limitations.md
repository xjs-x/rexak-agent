# 当前限制

- 推理适配范围为 OpenAI Chat Completions。Anthropic Messages、Gemini 和 OpenAI Responses 没有在当前设置中启用。阿里云百炼选项是一种目录格式，推理连接仍为 Chat Completions。
- OpenAI 标准模型目录按单个 `data` 列表读取。自定义分页参数、非标准响应格式、额外 Header、OAuth 和 URL 查询参数配置尚未实现。具有官方分页结构的百炼目录支持逐页查询。
- 模型 ID 最多 128 字符，对应现有 Run 字段限制。Provider ID 由最多 64 个字母、数字、点、连字符和下划线组成，首字符为字母或数字。保存后可更改显示名称。
- 目录返回证明列表可读取。能力声明可配置，单模型推理、Function Calling、图像和 Thinking 的交互式验证尚未实现。当前通用协议沿用已有 SDK 的请求字段，网关需要兼容这些字段。
- 对规格未知的模型，控制端使用 8,192 tokens 的基础运行预算，以及最多 1,024 tokens 的默认单次输出预算。显式设置了更大的请求预算且未填上下文时，运行预算为输入留出至少 4,096 tokens 的空间，再应用安全余量。原始模型规格仍可留空。
- 百炼官方独立目录格式使用 Mock 验收。实际百炼环境此次通过 OpenAI 兼容目录直接获取成功。
