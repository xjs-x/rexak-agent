# 前后端变更

- 控制端新增提供商新增、更新、删除和草稿查询接口。原模型设置 GET 仍提供扁平运行档案，另外返回分组目录和修订号；原 PUT 可编辑已有模型的连接与默认值。
- 设置层延续同一个文件和本地 Key 库。首次写入升级前保留旧文件。提供商和模型的启用状态影响新阶段的选择。删除或停用默认模型时，从启用且已填写地址的模型中重新选择。
- Main 根据 Provider 和 Model 的目录配置生成运行档案。Worker 从同一个可信控制端通道解析固定的绑定和凭据槽。旧小米和百炼配置沿用各自原来的推理适配器。新 Provider 使用通用 Chat Completions 适配器。
- 前端提供商列表、连接表单、模型编辑器和目录弹窗共用生成的 OpenAPI 类型。聊天模型选择器显示配置后的提供商名称和模型显示名称，提交真实 Model ID。
- 验收包括本地 HTTP Mock、隔离数据库与密钥库、实际 Edge 控制台操作，以及一次百炼只读目录查询。
