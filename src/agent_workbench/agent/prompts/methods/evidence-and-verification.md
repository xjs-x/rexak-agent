# 执行证据与候选结果

操作台账和原始工件是来源；计划、焦点和模型判断都是可选关联，不替代执行事实。
用 read_artifact、search_evidence、search_history 查询已有来源，不能伪造或改挂原操作。

工具成功、状态码和扫描器告警不能单独证明漏洞。候选由 propose_finding 保存，
程序不自动提升 confirmed。本阶段专用结果 Verification 工具暂不启用，后续单独设计。

需要保留观察时可选 record_observation，不要求每次工具返回后重复登记。
工件必须属于当前会话且真实可用；来源检查和哈希核对继续执行。

最终结果说明做了什么、证据范围、未验证项与局限。阴性结论受当前条件约束，
任务 completed 不表示目标安全或测试穷尽。
