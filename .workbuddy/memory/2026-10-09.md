### 联调中真实抓到的缺陷（都已修复）

1. **脱敏顺序错误导致令牌泄漏**：`Authorization: Bearer <token>` 先被键值规则吃掉
   "Bearer"，令牌本体残留在结果里。改为先处理 Bearer/Basic 再按键值打码。
   由单元测试发现。
2. **范围载荷带多余字段**：Executor 的 `ScopeRulePayload` 是 `extra="forbid"`，
   控制端把内部 `notes` 一起发过去导致 422。同时改为区分
   `ExecutorRejected`（4xx，确定未执行）与 `ExecutorConnectionError`（副作用不确定）。
3. **工具异常中断整轮图**：`create_agent` 默认向上抛；改为在
   `ToolDispatchMiddleware` 分类转成终结 `ToolMessage`（CancelledError 仍传播）。
4. **配置错误把 Runner 卡死**：缺模型凭据时 `create_agent` 装配在深层抛
   `SecretNotFoundError`，`step()` 一路抛出，一个坏 run 把所有后续 run 都堵住。
   修复：开跑前预检（凭据 + Executor `/capabilities`），`step()` 捕获单 run 异常并落
   FAILED 后继续。
5. **lease 过期接管未递增 generation**：`claim_run` 走条件 UPDATE 分支时跳过递增，
   导致前任 owner 的迟到响应仍能通过所有权检查。
6. **queued run 无法直接取消**：状态机缺 `QUEUED -> CANCELLED`。
7. **grader 自污染**：评测读取 `/__fixture__/counters` 自身会计数，从 delta 里排除。
